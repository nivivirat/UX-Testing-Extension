# Privacy policy — KHDA Visual QA Capture

KHDA Visual QA Capture is a testing tool. It only acts when the user clicks its toolbar.

- **What it stores:** issues the user reports (title, description, status), screenshots of the page
  the user is testing, and details of the selected page element (CSS values, component names).
- **Where:** only in the browser's local extension storage on the user's own computer.
- **Sharing:** nothing is sent to any analytics service or third party. Data leaves the computer
  only when the user clicks **Export ZIP** or **Download backup** (a file in the Downloads folder),
  or — if the user connects their organisation's own Redmine in Settings — when issues are created
  or updated in that Redmine. The Redmine API key is stored only in the browser and is never
  exported or included in backups.
- **Personal data:** emails, phone numbers, Emirates IDs and filled form fields are blurred on
  screenshots by default. Users can blur anything else before saving.
- **Removal:** deleting an issue, "Delete all issues" or removing the extension deletes the data.

Contact: the repository owner on GitHub.
